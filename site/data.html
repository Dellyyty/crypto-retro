Data · provenance

Every number, traced.

CRYPTOCAST reads six public HTTP APIs directly from your browser. No proxy, no server, no key, no database. This page lists each one, what it feeds, how often it is polled, and what happens when it fails.

Keyless by design. Every endpoint above served access-control-allow-origin: * when verified on 2026-11-07. Nothing in this repo holds a credential. If a provider adds a key requirement, that panel degrades to — rather than silently showing stale values.

Polling model

Two timers, both paused when the tab is hidden by the browser's own throttling and by visibilitychange for audio. Market and chain data share one 60-second sweep; candles use a slower 5-minute sweep because daily OHLCV does not change meaningfully inside a minute and Coinbase rate-limits per IP.

t=0     loadCandles()  3 candle requests, parallel

Boot behavior

  1. Read localStorage["cryptocast.cache.v1"] and render immediately. First paint shows the last snapshot, not skeletons.
  2. Fire the network sweep in parallel with the TV turn-on animation.
  3. Overwrite rendered values as each response lands. No layout shift: every field is fixed-width and tabular.
  4. Persist the merged snapshot after each sweep.

Rate limits and etiquette

  • CoinGecko free tier: roughly 10–30 calls/minute per IP. CRYPTOCAST uses 2 per minute.
  • mempool.space: generous, but five requests per minute is well inside courtesy bounds.
  • Coinbase Exchange: 10 requests/second per IP; CRYPTOCAST uses 3 per 5 minutes.
  • No user-agent spoofing, no scraping of HTML, no retries with backoff storms — a failed sweep is skipped, not hammered.

Moon phase

Age = ((now − 2000-01-06T18:14Z) mod 29.530588853 days). Phase names use the four principal quarters with crescent/gibbous interludes, matching the four-phase card the reference broadcast shows.

Halving countdown

Target = (floor(height / 210000) + 1) × 210000. ETA assumes 10-minute blocks. Subsidy = 50 / 2^(era−1). Issuance percent sums completed eras plus the partial era, against the 21,000,000 cap — which is why the figure never quite reaches 100%.

Precision limits you should know

  • CoinGecko aggregates across venues, so BTC price can differ from Coinbase by tens of dollars.
  • Candles are Coinbase USD spot only — a single venue, not a composite index.
  • Funding is Hyperliquid's hourly rate normalized to 8 h; other venues quote differently.
  • Difficulty retarget progress is based on the node's estimate, not a protocol guarantee.
  • Moon phase is an approximation good to a few hours; it is decoration with real math behind it.
